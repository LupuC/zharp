# Windows changelog

Generated by release-please from the conventional commits under `windows/`. It
starts empty because Windows has not released from this repository yet: everything
up to and including 0.16.0 is in the [root changelog](../CHANGELOG.md).

Windows carries its own patch number. A bug fix here moves it without touching the
other platforms, which is why this file exists separately. The line it sits on,
the `0.16` in `0.16.2`, is shared by every platform and moves for all of them
at once.
