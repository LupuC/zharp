# macOS changelog

Generated by release-please from the conventional commits under `macos/`. It
starts empty because macOS has not released from this repository yet: everything
up to and including 0.16.0 is in the [root changelog](../CHANGELOG.md).

macOS carries its own patch number. A bug fix here moves it without touching the
other platforms, which is why this file exists separately. The line it sits on,
the `0.16` in `0.16.2`, is shared by every platform and moves for all of them
at once.
